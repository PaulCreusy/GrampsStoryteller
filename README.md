# GrampsStoryteller

A [Gramps](https://gramps-project.org) tool that writes, in a note attached to a
person, the **historical context** of the places and periods where this person
lived. The text is generated by the LLM of your choice from **Wikipedia
excerpts**, which are cited in the note.

**No identifying data leaves Gramps**: the LLM only receives unlabeled years and
places (and, if you enable it, the occupation). It never receives a name, an
identifier, an event type, a relative or a note of your tree.

## Requirements

- Gramps 6.0 (5.1 and 5.2 support is planned).
- Network access to Wikipedia and to the LLM provider.
- An API key for a cloud provider, or a local server (Ollama, LM Studio...).

No extra Python package is needed: the addon only uses the standard library.
If the `keyring` package is available in Gramps' Python, API keys are stored in
the system keyring.

## Installation

### From Gramps' Addon Manager (recommended)

1. In Gramps, open **Help ▸ Addon Manager**.
2. Open the **Projects** tab and click **+**.
3. Enter a name (e.g. `GrampsStoryteller`) and this URL:

   ```
   https://raw.githubusercontent.com/PaulCreusy/GrampsStoryteller/main/addons/gramps60
   ```

4. Back in the **Addons** tab, pick **Storyteller: historical context** and click
   **Install**.
5. Restart Gramps. The tool appears in **Tools ▸ Family Tree Processing**.

### Manual installation

Extract `addons/gramps60/download/GrampsStoryteller.addon.tgz` into the Gramps
user plugins directory (e.g. `~/.local/share/gramps/gramps60/plugins/`), then
restart Gramps.

## Usage

1. Select a person in the People view.
2. Open **Tools ▸ Family Tree Processing ▸ Storyteller: historical context**.
3. Click **Settings...** once to choose the provider, the model and the API key.
4. **Preview the request** shows exactly what will be sent (nothing is sent to
   the LLM at this step, only to Wikipedia).
5. **Generate the note** writes the note. Running it again replaces the note.

## What is sent

| Data | Sent to | Notes |
| --- | --- | --- |
| Birth year and place (fallback: baptism) | Wikipedia, LLM | Year only, without label |
| Death year and place (fallback: burial) | Wikipedia, LLM | Year only, without label |
| Occupation | LLM | Only if "Send the occupation" is ticked |
| Postal / INSEE code of the place | nobody | Used locally to find the department, region and historical province |
| Names, IDs, relatives, marriages, notes | nobody | Never read |

Living persons and private persons, events or places are always excluded.

## How the context is sourced

For each place the addon looks for Wikipedia articles from the most local to the
broadest level, because small communes rarely have a detailed history:

1. the commune;
2. its department (from the postal/INSEE code entered in the place **Code**
   field, or from the place hierarchy);
3. the historical province (e.g. Bretagne, Normandie) and, for recent years, the
   current region;
4. the national periods covering the years (e.g. Monarchie de Juillet, Third
   Republic), or the history article of a foreign country.

Only the paragraphs of the history sections that match the years are kept. When
the local sources are rich, the LLM may only use outside knowledge for the daily
life paragraph; otherwise it may add well-established general knowledge anywhere.
General knowledge is shown in italics, with a one-line legend.

The text has three short paragraphs, from the general to the particular: the
national and regional context, the local context, then the daily life of an
inhabitant (housing, food, work, religion...). Sources are not cited inline: they
are listed at the end of the note.

## Note

The note contains the context, the list of the cited Wikipedia revisions and a
discreet line with the generation date and model. It has the type
"Life story" and the tag `Storyteller`.

## Settings

Settings are stored in `~/.config/grampsstoryteller/settings.json` (Windows:
`%APPDATA%\grampsstoryteller`). Keys are read, in order, from the provider
environment variable (`OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `GEMINI_API_KEY`,
`MISTRAL_API_KEY`...) or `GRAMPSSTORYTELLER_API_KEY`, the system keyring, then
`credentials.ini` (readable by the owner only). Wikipedia answers and generated
texts are cached in `~/.cache/grampsstoryteller`.

The prompts can be edited in the settings; the variables are `{reperes}`,
`{profession}`, `{sources}`, `{consigne_sources}`, `{langue}`, `{longueur}` and,
for the optional LLM check, `{texte}`.
